# Iris · 衣橱灵感库

穿搭灵感、待购计划与日常衣橱管理。

## 功能

- 五个阶段：灵感池、重点参考、待购候选、已有可复刻、实穿记录
- 按场景、厚薄、单品、配色、版型、喜欢重点和优先级筛选
- 收藏、原图与效果图切换、笔记、预算、上传新图片、导入导出备份
- 当前收录23张效果图（含1张待修正版）和18张参考原图，不代表完整聊天历史

## 数据保存

管理修改和新上传图片保存在当前浏览器的 IndexedDB，不会自动写回 GitHub，也不会跨设备同步。换设备、清理浏览器前请先导出管理备份。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。

根目录 index.html 为网页入口，无需安装依赖或构建。
